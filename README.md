<h1>Online Retail Store Analytics Project</h1>

<h2> Project Overview </h2>
This project analyses transactional data from an online retail business to identify key revenue drivers, customer purchasing behavior and retention patterns. The analysis was conducted using Python, SQLite, SQL and Tableau Public to transform raw transactional data into actionable business insights.


The dataset contains over 1,000,000 retail transactions from 2009 to 2011 across multiple countries and products.

<h2> Goal </h2>
The primary goal of this project was to better understand:


1. What drives revenue growth?

2. Which customers contribute the most value?

3. How customer retention impacts revenue?
